# v169 リリースノート

## 変更点

### Google TTS 使用量カウントの精度改善
- 会話文ピッチ・速度変更（SSML）がONの場合、Googleへ実際に送信するSSML文字列（`<speak>`・`<prosody>`タグ込み）の長さでカウントするよう修正。従来はプレーンテキスト長のみでカウントしており、Google Cloud Console側の実際の課金カウントとアプリ内カウントが乖離していた（Chirp3系はSSMLを使用しないため元々乖離なし）。
- 設定タブの「読み上げ演出」セクションに、ONにするとSSMLタグ分の文字数がカウントに上乗せされる旨の注記を追加。

### 長文セグメントでの読み上げ停止を修正
- `startWatchdog()`のタイムアウト上限を60秒→180秒に拡大。長文セグメント（300文字超）で実際の再生時間がタイムアウトを超え、同一セグメントの再取得を無限に繰り返して読み上げが先に進まなくなる不具合を修正。

### タブ切替時の読み上げ停止を修正
- タブ（読む／履歴／設定）切替時に600ms間だけ次セグメントへの進行をブロックしていた`_tabSw`ガードを廃止。`<audio>`要素はタブ切替の影響を受けない位置に配置されており、このガードに実害はなく、切替タイミングによっては読み上げが停止したまま進まなくなる副作用のみが発生していたため。

### URL読み込み時の自動再生を廃止
- 目次URLからの章選択・章URLの直接読み込み・しおりからの再開のいずれも、`loadChapterUrl()`内の`startPlay()`呼び出しを削除。本文表示後は▶ボタン押下を起点に読み上げを開始するよう統一（履歴タブからの再開は元々この挙動）。

### UIレイアウト・配色の調整
- コントロールバーの5ボタン（前話／戻る／再生／進む／次話）を`justify-content:space-evenly`に変更し、横画面でも均等配置されるようにした。
- 設定タブのセクション順を並び替え：読書統計→今月の使用量→音声を選ぶ→使用量・請求確認→Google Cloud TTS→読み上げ演出→省略設定→読み間違い辞書→背景エフェクト→データ管理。従来1つのセクションに同居していた「今月の使用量」「使用量・請求確認」「Google Cloud TTS」を独立したセクションに分割。起動時にGoogle音声選択セクションを前のセクションと入れ替えていたJSの並び替え処理を削除し、HTML記述順がそのまま表示順になるようにした。
- 読書統計のリセットボタン列に「リセット」ラベルを追加。
- 設定タブの見出し色（`.sett-title`）・ラベル色（`.stats-lbl`/`.usage-bar-label`）を、使い方モーダルの配色（見出し`#c8991e`／本文`#9e8660`）に合わせて明るくし、視認性を改善。使い方モーダル側の暗いままだった注意書き（`.rdm-note`）・URL例テキストも同色に統一。
- 省略設定リストの区切り線・グループ見出し（— 基本フィルター／— 後書き・お願い系フィルター／— カスタムフィルター）の余白を縮小し、他の項目間と同じ行間ピッチに統一。
