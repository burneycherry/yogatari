# v179 リリースノート

## 変更点

### ブラウザのタブ・ブックマーク用アイコンを追加した

`index.html` に `<link rel="icon">` の指定が無く、ブラウザのタブ・ブックマークにアイコンが表示されなかった。

- `icon.svg`（夜空の背景・金色の三日月・星）を追加し、`<link rel="icon" type="image/svg+xml" href="icon.svg">` で指定した
- SVGアイコンに対応していない環境向けに `<link rel="icon" type="image/png" sizes="192x192" href="icon-192.png">` を併記した
- 16pxで判読できないため「夜」の文字は入れていない
- ホーム画面用の `apple-touch-icon` とマニフェストのアイコンは変更していない

### CLAUDE.md を要点に絞り、詳細を docs/guide/ へ分離した

504行から約180行にした。詳細は次の4資料へ原文のまま移した（見出しの「重要」表記とファイル間参照のみ変更）。

| 資料 | 内容 |
|------|------|
| `docs/guide/audio.md` | 音声パイプライン、バックグラウンド再生の実測挙動、デバッグモード |
| `docs/guide/sites.md` | テキスト処理、サイトパーサー、`SITE_RULES`、各サイトの実測事項 |
| `docs/guide/proxy.md` | CORSプロキシ、取得制御、Shift_JIS、削除済みプロキシ |
| `docs/guide/storage.md` | localStorage / sessionStorage のキー一覧 |

CLAUDE.md には「壊しやすい箇所」として各資料の要点（削除・変更してはならない処理とその理由）を1行ずつ残した。あわせて指示文の監査結果を反映した。

- 「記述ルール」と「言語ルール」の食い違い（説明コメントの言語）を解消し、ファイル内コメントは英語に統一した
- 重複していた記述（DRY原則と既存コード確認ルール、バージョン作成の禁止事項）を1か所にまとめた
- 過剰な強調表現と、以前の版との差分を指す見出し表記を除いた

### README.md を追加した

利用者向けに、概要・対応サイト・使い方・主な機能・Google TTSの設定・バックグラウンド再生の注意・開発方法・ファイル構成を記載した。
