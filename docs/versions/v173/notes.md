# v173 リリースノート

## 変更点

### APIキーの有無と再生エンジンの判定を分離
- APIキーを保存したままでは端末内蔵音声に戻せず、切り替えるにはAPIキーのクリアが必要だった問題に対応。
- 原因は `hasGoogleKey()`（APIキーの有無）が再生エンジンの判定を兼ねていたこと。エンジンの選択状態を新しいlocalStorageキー `yogatari_engine`（`'google'` / `'device'`）に分離し、再生経路の判定を `useGoogleTts()`（`_ttsEngine === 'google' && hasGoogleKey()`）へ置き換えた（14箇所）。
- `hasGoogleKey()` は「APIキーが保存されているか」の判定としてのみ残した。
- `yogatari_engine` が未設定の場合はAPIキーの有無から導出するため、既存ユーザーの挙動は変わらない。**新規キーの追加のみで既存キーの変更・削除がないためマイグレーションは不要。**
- APIキーが無い状態でGoogle音声を選んだ場合は選択自体を保持し、警告ノート（`gvKeyNote`）とトーストで案内したうえで、実再生は端末内蔵音声にフォールバックする。
- 使用量が98%に達した際の端末内蔵音声への自動フォールバックは従来どおり維持した。`isOverLimit()` の前提が `useGoogleTts()` になったため、端末内蔵音声を選択中は常に false となる。

### 設定タブ「// 再生音声を選ぶ」
- 見出しを「// Google音声を選ぶ」から「// 再生音声を選ぶ」へ変更し、セクションを常時表示にした（従来はAPIキーがある時だけ表示）。
- セレクトの先頭に端末内蔵音声（Web Speech API）の optgroup を追加し、Google音声と同一のセレクトから選択できるようにした。optgroup は `deviceVoiceOptgroupHtml()` が `SS.getVoices()` の結果から生成する。
- 試聴ボタンは端末内蔵音声を選択中なら `SpeechSynthesis` で試聴する。
- バックグラウンド再生の警告（`bgWarnNote`）を「Google Cloud TTS」セクションから試聴ボタン直下へ移動した。音声選択との関係を分かりやすくするための移動で、表示条件のロジックは変更していない。

### コントロールバーの音声表示をバッジに統一
- 音声の選択を設定タブへ集約したため、コントロールバーにあった端末内蔵音声のセレクト（`voiceSel`）を削除し、Google TTSと共通の読み取り専用バッジ1つに統一した。
- `voiceRowKyoko` / `voiceRowGoogle` の2行を `voiceModeRow` に統合し、バッジ `voiceModeBadge` が選択中のエンジンに応じて表示を出し分ける。
  - Google TTS: `🎙 Wavenet-A`（`mode-badge google`）
  - 端末内蔵音声: `🔊 <端末の音声名>`（`mode-badge`）
  - 98%超過のフォールバック中: `🔊 <端末の音声名>（制限中）`
- 未使用になった `onVoice()` と `loadVoices()` 内のセレクト構築処理を削除した。

### 飾り記号フィルターの追加
- カクヨム等で話タイトルの先頭に付く `◆` が「くろひしがた」と読み上げられ、タイトル表示・履歴・ロック画面（Media Session）にもそのまま出ていた問題に対応。
- 省略設定の基本フィルターに `decosym`（飾り記号）を追加した。既定ON。
- `stripDecoSym()` が行頭・行末の飾り記号（`◆◇■□●○◎◯★☆▲△▼▽▷◁♦♢♣♠♥♡※＊*†‡❖◈`）を除去する。適用先は `splitText()` の各行先頭（読み上げテキスト）と `extractPage()` 内の `extractTitle()` の結果（タイトル表示・履歴・Media Sessionの曲名）の両方。
- **除去は両端のみで行内は対象外。** 長音符（ー）・三点リーダ（…）・中点（・）・波ダッシュ（〜）・乗算記号（×）・ダッシュ（――）など本文の意味を持つ文字には影響しない。Nodeで実挙動を検証済み。
- 行全体が飾り記号の場合は空文字となり既存のフィルターで除外される。
- 行全体が記号のみの行を落とす区切り記号行フィルター（`divider`）とは対象が異なるため別項目とした。`divider` のパターンには `◆`(U+25C6) が以前から含まれており、判定の挙動は変更していない（ラベル表記に `◆` を明記しただけ）。

### 再生中のエンジン切り替えによる誤検知を修正
- `checkAudioProgress()` の先頭に `useGoogleTts()` ガードを追加した。
- 再生中にエンジンを切り替えると `gAudioEl` が読み込み済みのまま一時停止し、凍結した `currentTime` をセッション断絶と誤検知して「⚠ 中断 ▶で再開」を表示する経路があった。CLAUDE.mdに記載の不変条件（Web Speechモードでは動作せず誤検知もしない）を回復させる修正。

### 開発引継ノートの保管
- 過去セッションの開発引継ノート5件を `/docs/versions/history-v01-v53/`・`history-v54-v80/`・`history-v81-v110/`・`history-v111-v139/`・`history-v140-v162/` に `notes.md` として保存した。
- フォルダ名に `vXXX` 形式を使わないのは、「`/docs/versions/` 内の最大の vXXX を最新とする」状態認識ルールの判定を壊さないため。参照用の履歴記録であり、`index.html` への変更は伴わない。

## 決定事項

- 再生音声のUIは、エンジン切替ボタンを別に設けず**1つのセレクトに統合**する方式を採用した。
- 98%到達時の自動フォールバックは、ユーザーの選択より優先して従来どおり維持する（無料枠超過による課金を避けるため）。
- 読むタブのバッジで端末内蔵音声の名前をそのまま表示するのは、Androidでは `ja_JP` 系の日本語名が出るため違和感がないことをユーザーが確認済み。

## 未実装・対応予定なし

- Service Worker / オフライン対応: 引き続き対応予定なし
- SSMLポーズ最適化: 削除済み、復活予定なし
- Android での `rebuildAudioElements()` による復旧: v172の無音ループ対策により停止自体が起きなくなったため、追加対応は行わない
