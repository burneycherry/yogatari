# v175 リリースノート

## 変更点

### 履歴のサムネイルを小説サイト別のマークに変更
- 履歴一覧の左端にあった 📖 の絵文字（全作品で同じ表示であり情報を持っていなかった）を、取得元サイトが一目でわかるマークに置き換えた。
- `SITE_MARKS` 配列と `siteMarkOf(url)` を `toNovelId()` の直後に追加した。ホスト名の部分一致で判定する。`syosetu.com` はハーメルンの `syosetu.org` には一致しない。
- マークは各サイトのロゴを簡略化した36×36のインラインSVGで、`index.html` 内に直接記述する。**画像ファイルは追加していない**（完全単一ファイル原則）。
  - 小説家になろう: 白地に水色（`#2b9ebd`）の明朝体「なろう」、下端に水色（`#4cc0da`）の帯。
  - カクヨム: 青地（`#4590c9`）に白の鉤括弧「」を左上・右下に配置。
  - エブリスタ: 白地に青（`#3d9ad6`）の枠、吹き出しを模した大円・小円・点。
  - 青空文庫: 紺地（`#0b1668`）に白の外枠と縦罫線、明朝体で「文庫」「青空」の2列。
- 表示は `.hist-thumb-icon.site-logo` が担う。既存の枠線・背景を消してSVGを敷き、角丸6pxで切り抜く。
- **判定できないURLは従来どおり 📖 と枠付きタイルを表示する。** サイト追加時に表示が壊れないようにするため。
- これらは各社ロゴを簡略化して似せた図柄であり、公式ロゴ画像の複製ではない。

### エブリスタのNEWバッジが誤った話数を出す問題を修正
- `chapNumFromUrl()` がエブリスタで返すのは `?page=` の**作品全体の通しページ番号**（例: 全2648ページ中の1）であるのに対し、`_checkNewChapterImpl()` は目次の「全NNエピソード」（例: 69）を総数として保存していた。**単位の異なる値どうしの差**がNEWバッジに出ていた。
- 症状: 1ページ目で `NEW +68話`（69−1）と表示される。総ページ数より遥かに小さい値のため、70ページ目以降まで読むと差が負になりバッジが消える。
- 総数の取得元を目次の**ページ数**（「2648ページ」）に変更し、`?page=` と単位を揃えた。目次HTML内で `N ページ` に一致する数値のうち最大値を採用する（`2,648` のカンマ区切りにも対応）。
- `chapUnitOf(url)` を追加し、エブリスタのときだけ履歴・再開バナーの表記を「第Nページ」「NEW +Nページ」とした。他サイトは従来どおり「話」。
- ヘルプの「新着話の自動検出」に、エブリスタはページ番号で数える旨を1行追記した。
- 既存のしおりに保存済みの `totalChap`（エピソード単位）は、既存の `Math.max` ガードにより次回チェック時にページ数へ更新される。localStorageの構造変更は無く、マイグレーションは不要。

## 決定事項

- **エブリスタの単位はページ側に揃えた。** ページ番号からエピソード番号を逆算する案もあったが、目次のエピソード一覧は「もっと見る」で遅延読み込みされるため、静的HTMLから全エピソードの開始ページ番号を得られる保証がない。確実に動作する方を採った。
- サイトマークは画像ファイルではなくインラインSVGとした。公式ロゴ画像の使用にはファイル追加が必要で、完全単一ファイル原則に抵触するため。
- 未対応サイトのフォールバック（📖）は残した。

## 未実装・対応予定なし

- Service Worker / オフライン対応: 引き続き対応予定なし
- SSMLポーズ最適化: 削除済み、復活予定なし
- アルファポリス・ハーメルン: v174で非対応として確定済み
- エブリスタの目次ページからの話選択: 目次解析はなろう専用のため未対応
- エブリスタのエピソード単位での話数表示: 上記の理由によりページ単位のまま
