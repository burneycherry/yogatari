# 夜語り (Yogatari)

日本語Web小説を読み上げるPWA（Progressive Web App）。
小説サイトのURLを貼るだけで本文を取得し、端末内蔵の音声またはGoogle Cloud Text-to-Speechで読み上げる。話の終わりには次の話へ自動で進む。

- 公開URL: https://burneycherry.github.io/yogatari/
- 対象環境: iOS / Android の Safari・Chrome（ホーム画面に追加してのアプリ利用を推奨）

## 対応サイト

| サイト | 備考 |
|------|------|
| 小説家になろう（ncode.syosetu.com） | 目次URLから話を選べる |
| カクヨム（kakuyomu.jp） | 目次URLから話を選べる |
| エブリスタ（estar.jp） | 話のURLを貼って読み込む。目次からの話選択には非対応 |
| 青空文庫（www.aozora.gr.jp） | 本文ファイル（`/files/〜.html`）のURLを貼る。図書カードのページには本文が無い |

**非対応:** アルファポリス（本文がJavaScriptで後から読み込まれ、コピー防止機能もあるため）、ハーメルン（Cloudflare保護により本文を取得できないため）

## 使い方

1. 小説の目次URLをコピーし、「読む」タブに貼り付ける（例: `https://ncode.syosetu.com/n1234ab/`）
2. 「読込」を押し、表示された話一覧から読みたい話をタップする
3. ▶ で読み上げを開始する。話の終わりに3秒のカウント後、次の話へ自動で進む

アプリ内の「使い方」にも同じ説明がある。

## 主な機能

- **2つの読み上げエンジン** — 端末内蔵音声（APIキー不要）とGoogle Cloud TTS（高品質・APIキー必須）を設定タブで切り替える
- **再生コントロール** — 段落単位の前後移動、話をまたぐ移動、速度・ピッチ調整、画面の左右タップで5秒戻る／進む（Google音声時）
- **睡眠タイマー** — 15 / 30 / 60分で自動停止し、画面を暗転する
- **しおり・履歴** — 5段落ごとに自動保存し、履歴タブから再開できる
- **新着話の自動検出** — 起動時に履歴の作品を順にチェックし、未読の話数を表示する
- **省略単語・読み間違い辞書** — 特定の単語を含む段落のスキップや、読み上げ前のテキスト置換
- **読書統計・背景エフェクト** — 読書日数・作品数・話数・読み上げ時間の記録、天候が変わる夜空アニメーション

## Google TTS の設定（任意）

1. [Google Cloud Console](https://console.cloud.google.com) でプロジェクトを作成する
2. 「APIとサービス → ライブラリ」から Text-to-Speech API を有効化する
3. 請求先を設定する（無料枠あり）
4. 「認証情報」でAPIキーを発行し、設定タブに貼り付けて保存する

APIキーはこの端末のlocalStorageにのみ保存され、Google以外の外部サーバーには送信されない。

## バックグラウンド再生について

- **画面を消したまま聴けるのはGoogle音声を選んでいるときのみ。** 端末内蔵音声は、iPhone・Androidとも端末側の仕様により画面を消すと停止する
- 電話や他アプリの音声で中断されると、バックグラウンド再生が止まることがある。画面上部に「⚠ 中断 ▶で再開」と表示されたら ▶ をタップする
- ホーム画面に追加（共有 → ホーム画面に追加）すると動作が安定する

## 開発

ビルド・依存パッケージは無い。アプリ全体が `index.html` 1ファイルで完結している。

```sh
python3 -m http.server
# http://localhost:8000/ を開く
```

小説の取得は自前のCORSプロキシを経由する。プロキシは許可したオリジン（公開URLとlocalhost）からのリクエストのみ受け付けるため、`file://` で直接開くと取得できない。

### ファイル構成

| パス | 内容 |
|------|------|
| `index.html` | アプリ本体（HTML・CSS・JavaScript） |
| `manifest.json` / `icon-*.png` | PWAマニフェストとアイコン |
| `CLAUDE.md` | Claude Code向けの作業指針（開発ルール・バージョン管理プロトコル） |
| `docs/guide/` | 仕様・実測事項の詳細資料（音声・サイト・プロキシ・ストレージ） |
| `docs/versions/` | バージョンごとの構造記録と変更履歴 |

開発ルールは `CLAUDE.md`、各機能の詳細は `docs/guide/`、変更履歴は `docs/versions/` の最新版を参照。
